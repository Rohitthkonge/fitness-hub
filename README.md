# FITNESS HUB

An intelligent fitness, nutrition, and recovery companion engineered to help users achieve personalized goals through AI-powered routines and analytics.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Vanilla CSS with emerald-green Bento Grid design system

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Notes
- **Authentication**: Uses a simulated client-side session (`localStorage`) for demonstration and testing purposes.
- **AI Agent**: The interactive AI coach and routine generators provide demo/simulated insights and workout recommendations.
